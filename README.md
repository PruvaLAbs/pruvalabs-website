# PruvaLabs Web

PruvaLabs kurumsal sitesi ve PruvAI ürün tanıtım yüzeyi.

## Yerel geliştirme

```bash
npm install
npm run dev
```

Site varsayılan olarak `http://localhost:3000` adresinde açılır.

## Kontrol

```bash
npm run build
```

PruvAI ürün uygulaması bu depo içinde çalıştırılmaz. Bu site, ürünün genel
tanıtımını ve erken erişim iletişimini sunar.
